Исправление CI синхронизации (PR #6): тест оригинала `scripts/release/source-integrity.test.mjs` проверяет предыдущий релизный тег (`git cat-file -t v1.0.35`), а форк не зеркалил теги оригинала дальше `v1.0.34`. Выложены теги `v1.0.35` и `v1.0.36`; `fork/sync_upstream.py` теперь показывает недостающие релизные теги и публикует их с `--push-tags`.

Проверено локально: тесты дашборда (`scripts/dashboard/test_*.js`), `fork/apply_hooks.py --check`, YAML обоих workflow.
Не проверено: фактическая сборка APK и публикация релиза (запускаются только в GitHub Actions), поведение спойлера и ссылок в реальном приложении.

Осталось:
- Передача координат (п. 2) и карта (п. 3) требуют решений по протоколу: upstream молча отбрасывает LXMF-сообщения только с телеметрией (`FIELD_TELEMETRY`), а приём и показ потребуют нескольких хуков в `crates/ratspeak-runtime/src/lib.rs`. Нужен отдельный дизайн и PR.
- Перевод 123 новых строк оригинала на русский (`tools/i18n`).
